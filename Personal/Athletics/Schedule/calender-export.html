How to Upload to Thrillshare

After downloading the calendar file, use the Thrillshare calendar import feature to upload the .ics file.

Click Download ICS Calendar above.
Save the downloaded .ics file to your computer.
Open the school's Thrillshare Calendar.
Open the calendar's Import Events option.
Choose iCalendar as the import type.
Select the downloaded .ics file.
Complete the import and review the events.

Important

Google Sheets is the source of truth for the athletics schedule.

If a game changes in Google Sheets, generate a new calendar export before importing the updated schedule into Thrillshare.

This export page does not change the Google Sheet.
